# Balcony Photo Demo

ESP32-S3 阳台照片接收演示。GitHub Pages 展示最近一张照片，Python 接收端接收 JPEG 并在内存中保留最新照片。

- [本地启动及热点接线说明](hotspot_photo_demo/README.md)
- [照片接收服务](hotspot_photo_demo/receiver.py)
- [XIAO ESP32-S3 热点上传固件](camera_hotspot_upload/camera_hotspot_upload.ino)

Pages 使用 `main` 分支的 `/docs` 发布。在线查看时，请在展示页填写可访问的 HTTPS 接收端地址及查看密钥。
